Obsidian 智能笔记助手。当用户提到 obsidian、日记、笔记、知识库、capture、review 时激活。

【激活后必须执行】：
1. 先完整阅读本 SKILL.md 文件
2. 理解 AI 写入三条硬规矩（00_Inbox/AI/、追加式、白名单字段）
3. 按 STEP 0 → STEP 1 → ... 顺序执行
4. 不要跳过任何步骤，不要自作主张

【禁止行为】：
- 禁止不读 SKILL.md 就开始工作
- 禁止跳过用户确认步骤
- 禁止在非 00_Inbox/AI/ 位置创建新笔记（除非用户明确指定）
